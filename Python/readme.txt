Название проекта:"Написание скриптов на Python".
Стек технологий: 
🔹 python 3, формат логов Nginx, файл .log (вход), файл .txt (выход), командная строка Bash.

Описание проекта:
по условию проекта требовалось:
- написать скрипт для обработки лога веб-сервера;
- предоставить статистику обращений к этому сервису в отдельном txt-файле:
  - статистика при этом должна содержать IP-адрес и количество обращений;
  - сведения об операционной системе.
 
Вывод:
Скрипт на Python успешно обработал лог веб‑сервера и сформировал статистику обращений. Результат сохранён в TXT‑файле в формате «IP‑адрес: количество обращений», а также дополнен сведениями об ОС (по опциональному заданию). Решение масштабируемо и готово к регулярному использованию.

[1] Подробное описание находится в файле "Практическая работа.docx".
