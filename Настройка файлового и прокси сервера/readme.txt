Название проекта:"Настройка файлового и прокси-сервера".
Стек технологий:

Описание проекта:

по условию этого проекта треебовалось:
- создать прокси- и файловый сервер;
- настроить автомонтирование ресурсов по протоколу CIFS:
  - доступ к удалённой файловой системе нужно настроить для конкретного пользователя;
  - для автоматического монтирования использовать утилиту 'autofs'.
