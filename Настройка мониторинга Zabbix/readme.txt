Название проекта: "Настройка мониторинга - запуск Zabbix".

Стек технологий:
🔹 Zabbix (сервер + веб‑интерфейс), Zabbix Agent, Web Scenarios (Zabbix), Triggers и Templates (Zabbix), веб‑панель Zabbix, ICMP (icmpping), MySQL, ufw, php8.1, systemd, wget.

Описание проекта:
по условию проекта требовалось:
- настроить мониторинг Zabbix для мониторинга сайта yandex.ru;
- проверить доступность всего сервера по сети с помощью ключа icmpping;
- настроить зависимости проверок.

Выводы:
проект «Настройка мониторинга — запуск Zabbix» успешно завершён. Развёрнута и настроена система мониторинга Zabbix, обеспечивающая:
- контроль доступности веб‑сайта yandex.ru (через Web Scenarios);
- проверку сетевой связности сервера (через icmpping);

управление зависимостями между проверками для снижения числа ложных оповещений.

Система готова к эксплуатации: все метрики собираются, графики строятся, триггеры срабатывают корректно, уведомления поступают вовремя.
