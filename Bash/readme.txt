Название проекта: "Написание скриптов на Bash".

Стек технологий: 
🔹 bash, tar, SCP, SSH, sshpass, systemd, Linux.

Описание проекта: 
в этом проекте требовалось настроить регулярное резевное копирование:
- создать папку, в которой пользователи хранят файлы;
- написать скрипт, который:
  - будет автоматически архивировать эти папки;
  - регулярно копировать архив на другой сервер по протоколу SCP при помощи планировщика.

Выводы: 
- успешно настроена система регулярного резервного копирования: скрипт на Bash архивирует данные и передаёт их на удалённый сервер по SCP;
- реализована полная автоматизация процесса — от создания папки и архивации (tar) до копирования (SCP) и логирования операций;
- настроены два сервера (источник и приёмник бэкапов) с безопасной передачей данных через SSH/SCP.
- обеспечена регулярность выполнения задачи за счёт планировщика systemd (с использованием .service и .timer файлов).

[1] Подробное описание находится в файле "Практическая работа.docx"
[2] Текстовый файл с конфигурацией юнитов планировщика и скриптом находится в файле "Конфигурации.docx".
