Название проекта: "Написание скриптов на PowerShell".

Стек технологий:
🔹 PowerShell, командлеты: 'Invoke-WebRequest', 'Test-NetConnection', 'Get-Date', 'Add-Content', 'Write-Host', UFW (Uncomplicated Firewall), файл логов /var/log/web_checks/script.log, функции: 'WebRequest', 'CalcTime', 'CalcWeight', циклы (for/foreach), условные операторы (if‑else), переменные и массивы для сбора данных, протоколы: HTTP/HTTPS, TCP/IP, ICMP.

Описание проекта:
в этом проекте требовалось:
- настроить сервер для работы с PowerShell;
- написать скрипт проверки доступности сайта mail.ru.;
- смоделировать поведение скрипта при успешной и неуспешной проверке.

Выводы:
проект «Скрипт для мониторинга внешнего сайта» успешно завершён. Разработан PowerShell‑скрипт, который:
- проверяет доступность сайта (на портах 80 и 443) в трёх итерациях;
- требует передачи URL как параметра;
- подсчитывает среднее время отклика и средний размер ответа;
- ведёт детальное логирование в файл /var/log/web_checks/script.log;
- корректно реагирует на ошибки (отсутствие параметра, недоступность сайта).
Скрипт протестирован в трёх сценариях: успешная проверка, имитация сбоя (через UFW), вызов без параметра. Все сценарии отработаны корректно, сообщения информативны и понятны. Решение готово к эксплуатации.

[1] Подробное описание находится в файле "Практическая работа.docx".
