Название проекта:"Диагностика сетевой инфраструктуры".

Стек технологий: 
🔹 VLAN, IPv4, статическая маршрутизация, L3-коммутаторы, firewall, ACL.

Описание проекта:
- проект реализует сетевую инфраструктуру для двух независимых организаций, размещающих серверы у общего арендодателя. 

Решение обеспечивает:
-логическую изоляцию сетей организаций;
-доступ компьютеров к шлюзу своей подсети;
-связь между площадками;
-ограничение доступа между сетями организаций (каждая видит только свой сервер).

Выводы:
- создана логически изолированная сетевая среда для двух организаций (VLAN + trunk‑порты);
- реализован inter‑VLAN routing (на L3‑коммутаторе) и связь между площадками;
- обеспечен контроль доступа между сетями через ACL;
Инфраструктура готова к эксплуатации и полностью соответствует требованиям ТЗ.
