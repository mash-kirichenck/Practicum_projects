Название проекта: "Запуск NFS-сервиса и объектного хранилища".
Стек технологий: ОС Linux (Ubuntu),nfs‑kernel‑server,nfs-common,MinIO,mc (MinIO Client),nginx,systemd,ufw.

Описание проекта:
по условиям проекта требовалось:
- настроить файловый сервер на базе NFS для удалённого монтирования директорий по сети;
- развернуть объектное хранилище MinIO;
- предоставить к хранилищу доступ через прокси-сервер.

Выводы:
- успешно развёрнут NFS‑сервер на Linux для удалённого монтирования директорий;
- запущено объектное хранилище MinIO с управлением через mc;
- настроен прокси‑сервер для защищённого доступа к хранилищу;
- службы автоматизированы через systemd.
Система готова к эксплуатации и полностью соответствует ТЗ.

[1] Подробные настройки находятся в файле "Практическая работа .docx".
