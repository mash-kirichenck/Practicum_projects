Название проекта: "Запуск кластера баз данных PostgreSQL"

Стек технологий:
🔹 PostgreSQL, Streaming Replication (Active/Standby), pg_basebackup, psql, конфигурационные файлы: pg_hba.conf, postgresql.conf.

Описание проекта:
по условию проекта требовалось:
 - установить PostgreSQL;
 - настроить кластер  в режиме Active/Standby;
 - cоздать базу данных; 
 - настроить три виртуальные машины: 2 из них будут выступать в качестве кластера баз данных, а третья - в качестве клиента БД. 
 - подключится с клиентской машины к кластеру баз данных.

Выводы:
- развёрнут кластер PostgreSQL (Active/Standby) с Streaming Replication на двух ВМ;
- создана база данных;
- настроена клиентская ВМ и подтверждено подключение к кластеру;
- инфраструктура готова к эксплуатации;
- cистема обеспечивает отказоустойчивость и доступность данных при сбоях основного узла.

[1] Подробная информация по настройке указана в файле "Практическая работа.docx".
